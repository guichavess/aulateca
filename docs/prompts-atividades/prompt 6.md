ESTA ATIVIDADE DEVE TER 16-18 PÁGINAS.

frases e textos buscando pistas (classes de palavras,

AFIRMAÇÃO: SIM, CERTAMENTE, REALMENTE

Página 12 — CASO 9: Figuras de Linguagem — O Código Secreto (5° ano ⭐⭐⭐)
"As figuras de linguagem são como CÓDIGOS SECRETOS.

"Usa COMO, PARECIA, TAL QUAL para comparar duas coisas."
"Seus olhos brilhavam COMO estrelas."
"O menino corria COMO o vento."

"Compara SEM usar 'como'. Diz que uma coisa É outra."

"Dá qualidades HUMANAS a coisas ou animais."

"EXAGERA pra dar ênfase."

"Imita SONS."
